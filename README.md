# Vaahana Beta 📱✨

A high-fidelity, mobile-first mobility registration platform featuring premium **iPhone-style Glassmorphism** aesthetics.

![Vaahana Preview](https://github.com/Mohana-Sundar-M/Vaahana-beta/raw/main/preview.png) *(Note: Placeholder for actual preview if available)*

## 🚀 Vision
Vaahana Beta is designed to capture urban mobility patterns with a focus on visual excellence and user engagement. It leverages advanced CSS techniques and Framer Motion to deliver a "native app" feel on the web.

## ✨ Key Features
- **Premium Glassmorphism UI**: High-fidelity cards, inputs, and custom dropdowns with backdrop blur and vibrant saturation.
- **Mobile-First Architecture**: Vertical-stack registration flow optimized for one-handed use on mobile devices.
- **Sleek Urban Tracker**: A minimalist, glowing progress bar that scales perfectly across viewports.
- **Custom `GlassSelect` Components**: Replaced native browser elements with high-fidelity, animated dropdowns for a seamless experience.
- **Strict Content Alignment**: 1:1 matching with the final questionnaire specifications (8-step flow).
- **Dynamic Node Integration**: Automatically syncs custom locations ("Other place") into the rating logic.
- **Atmospheric 3D Backdrop**: Fixed low-poly city environment with smooth transitions (static view for performance).

## 🛠️ Tech Stack
- **Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS (v4) + Vanilla CSS Glass Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Mohana-Sundar-M/Vaahana-beta.git
   ```
2. Navigate to the project directory:
   ```bash
   cd vaahana-beta
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

### Production Build
To create a production-optimized bundle:
```bash
npm run build
```
